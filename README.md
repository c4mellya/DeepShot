# DeepShot

DeepShot 是适用于 Windows 10 22H2 / Windows 11 x64 的截图与桌面贴图工具。使用 C#、.NET 10 与 WPF 构建，提供简体中文与英文，Claude / DeepSeek 两套配色 × 浅色 / 深色 / 跟随系统。

仓库：[c4mellya/DeepShot](https://github.com/c4mellya/DeepShot) · [English](README.en.md)

## 安装与启动

优先运行发布目录中的 `DeepShot-0.4.0-Setup-x64.exe`，按当前用户安装，无需管理员权限。也可以解压 `DeepShot-0.4.0-win-x64.zip` 后，打开 `DeepShot` 文件夹并运行 `DeepShot.exe`。程序自带 .NET 运行时，不需要另装 .NET；ZIP 版本需要保留同目录的所有文件及 Resources 子目录。

程序启动后驻留系统托盘，图标可能位于“显示隐藏的图标”面板。首次启动显示使用引导。历史图库与设置共用一个主窗口（关闭它不会退出）；右键托盘图标选择“退出”才结束程序。开机启动默认关闭，可在设置中开启。安装包未签名。

## 截图与标注

- **Alt+A**：冻结鼠标所在屏幕。悬停识别整个窗口，单击采用候选，拖动自行框选。
- **Alt+Shift+A**：快速截图。手动框选后松开鼠标，直接复制到剪贴板并关闭截图；Esc 或右键取消，无需再按 Enter。
- 框选后调整位置或八向手柄，再使用矩形、椭圆、箭头、直线、画笔、文字和马赛克。
- 开始标注后选区锁定；撤销全部标注后可重新调整选区。
- **Enter** 复制；**Esc 或鼠标右键** 直接取消整次截图。文字输入时 Enter 确认文字，Shift+Enter 换行。
- **Ctrl+Z / Ctrl+Y** 撤销与重做。选择工具可移动、删除标注；双击文字重新编辑。
- 支持复制、另存为 PNG/JPEG、贴图。只有完成操作才记录历史，取消不会记录。
- 支持多屏、负坐标与不同缩放比例；一次截图限定在一块显示器内。

## 贴图

**Alt+S** 将剪贴板图片贴到桌面，也可从截图工具栏或历史图库创建贴图。

拖动移动；滚轮缩放；Ctrl+滚轮调整透明度（最低 20%）。右键提供原始大小、复制、另存为、锁定/解锁与关闭。锁定禁止拖动，仍可右键解锁。通过托盘统一隐藏/显示；退出后不自动恢复贴图。

## 历史快览

左键单击托盘图标打开最近 20 张图片的快览；右键继续展开原有菜单。默认快捷键为 **Alt+Q**，可在设置中修改或清除。快捷键打开时，快览窗口左上角对齐触发时的鼠标位置，并避让屏幕边缘。

鼠标在快览窗口内时，滚轮向上看上一张（较新），向下看下一张（较旧）；方向键也可翻图。点击缩略图跳转，Enter 复制当前图片并收起，Esc 或点击外部收起。大图和缩略图均可直接拖出到其他软件或文件夹。面板提供贴图、编辑和“完整历史”；进入完整历史时会定位当前图片，编辑复用现有编辑窗口。

## 历史与设置

托盘“历史”和快览里的齿轮会打开同一个主窗口：左侧是历史图库，右侧可以通过图库右上角齿轮进入设置；设置页用左栏分类 + 右侧内容区（通用 / 快捷键 / 外观 / 数据 / 关于），改动即保存。关闭主窗口只是收起，进程与托盘继续运行。

图库右侧有一条**时间索引**刻度轨：悬停显示月份与条数，点击跳到该月；头部日历按钮可打开日期弹层，按年 / 月 / 日跳到具体日期，并带“今天”快捷项。跳转后从该日期开始向下浏览，右上角“回到最新”返回第一页。

图库提供日期分组、名称搜索（Ctrl+F）、收藏、重命名、预览、复制、另存、贴图、删除与追加标注。普通记录默认按创建时间保留 30 天，可在设置的数据分类里改为 1–3650 天；按 Enter 或离开输入框自动保存，下次启动或跨日清理使用新值。收藏不自动清理，重命名与编辑不延长期限。

按住历史缩略图或预览大图拖到其他软件窗口或文件夹，可像资源管理器一样传递原始 PNG 文件。拖放仅允许复制，不移动历史原图；Esc 取消拖放。是否接收及是否立即发送由目标软件决定。

追加标注通过“保存并覆盖”更新同一条记录，不保留旧版本。取消编辑保留原图。旧标注已经合并在图片里，不能拆分修改。正在显示的贴图保留创建时的图像。

设置支持修改快捷键、默认截图方式、语言、主题及开机启动。默认截图方式可选“手动框选矩形”或“自动捕获窗口”，自动保存并在下一次截图生效。手动模式只按鼠标拖动框选；窗口模式悬停识别、单击选中，也可拖动框选。截图、快速截图、贴图和快览均可自定义快捷键，支持 Ctrl / Alt / Shift / Win 加主键的两键或三键组合，主键可用字母、数字、功能键、方向键、空格、小键盘或标点。快捷键冲突时会提示。

外观可选择 **Claude / DeepSeek** 两套配色品牌，明暗可选浅色 / 深色 / 跟随系统；切换立即应用到所有窗口，贴图与截图遮罩的深色玻璃层保持固定高对比。

截图和历史均保存于本机 `%LOCALAPPDATA%\DeepShot`。另存为的导出文件不受历史自动清理影响。卸载默认保留数据；交互卸载时可明确选择删除。检查更新会查询 [GitHub 最新正式 Release](https://github.com/c4mellya/DeepShot/releases/latest)，比较当前版本并展示更新说明，可打开发布页下载；网络失败会明确提示。不自动上传图片或下载安装更新。
