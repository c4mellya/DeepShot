# Zeep Cut

Windows 10 22H2 / Windows 11 x64 截图与桌面贴图工具。使用 C#、.NET 10 与 WPF 构建，提供简体中文与英文、浅色/深色及跟随系统主题。

## 安装与启动

优先运行发布目录中的 `ZeepCut-0.1.7-Setup-x64.exe`，按当前用户安装，无需管理员权限。也可以解压 `ZeepCut-0.1.7-win-x64.zip` 后运行 `ZeepCut.exe`。程序自带 .NET 运行时，不需要另装 .NET；ZIP 版本需要保留同目录的所有文件及 Resources 子目录。

程序启动后驻留系统托盘，图标可能位于“显示隐藏的图标”面板。首次启动显示使用引导。关闭图库或设置窗口不会退出；右键托盘图标选择“退出”才结束程序。开机启动默认关闭，可在设置中开启。安装包未签名。

## 截图与标注

- **Alt+A**：冻结鼠标所在屏幕。悬停识别整个窗口，单击采用候选，拖动自行框选。
- 框选后调整位置或八向手柄，再使用矩形、椭圆、箭头、直线、画笔、文字和马赛克。
- 开始标注后选区锁定；撤销全部标注后可重新调整选区。
- **Enter** 复制；**Esc 或鼠标右键** 直接取消整次截图。文字输入时 Enter 确认文字，Shift+Enter 换行。
- **Ctrl+Z / Ctrl+Y** 撤销与重做。选择工具可移动、删除标注；双击文字重新编辑。
- 支持复制、另存为 PNG/JPEG、贴图。只有完成操作才记录历史，取消不会记录。
- 支持多屏、负坐标与不同缩放比例；一次截图限定在一块显示器内。

## 贴图

**Alt+S** 将剪贴板图片贴到桌面，也可从截图工具栏或历史图库创建贴图。

拖动移动；滚轮缩放；Ctrl+滚轮调整透明度（最低 20%）。右键提供原始大小、复制、另存为、锁定/解锁与关闭。锁定禁止拖动，仍可右键解锁。通过托盘统一隐藏/显示；退出后不自动恢复贴图。

## 历史快览

左键单击托盘图标打开最近 20 张图片的快览；右键继续展开原有菜单。也可在设置中配置可选的“快览快捷键”，默认不占用按键。

鼠标在快览窗口内时，滚轮向上看上一张（较新），向下看下一张（较旧）；方向键也可翻图。点击缩略图跳转，Enter 复制当前图片并收起，Esc 或点击外部收起。大图和缩略图均可直接拖出到其他软件或文件夹。面板提供贴图、编辑和“完整历史”；进入完整历史时会定位当前图片，编辑复用现有编辑窗口。

## 历史与设置

托盘打开历史图库，可按日期查看、搜索名称、收藏、改名、预览、复制、保存、贴图、删除或追加标注。普通记录按创建时间保留 30 天，收藏不自动清理；重命名与编辑不延长期限。

按住历史缩略图或预览大图拖到其他软件窗口或文件夹，可像资源管理器一样传递原始 PNG 文件。拖放仅允许复制，不移动历史原图；Esc 取消拖放。是否接收及是否立即发送由目标软件决定。

追加标注通过“保存并覆盖”更新同一条记录，不保留旧版本。取消编辑保留原图。旧标注已经合并在图片里，不能拆分修改。正在显示的贴图保留创建时的图像。

设置支持修改快捷键、默认截图方式、语言、主题及开机启动。默认截图方式可选“手动框选矩形”或“自动捕获窗口”，自动保存并在下一次截图生效。手动模式只按鼠标拖动框选；窗口模式悬停识别、单击选中，也可拖动框选。快捷键冲突时会提示。

截图和历史均保存于本机 `%LOCALAPPDATA%\ZeepCut`。另存为的导出文件不受历史自动清理影响。卸载默认保留数据；交互卸载时可明确选择删除。更新渠道尚未配置，检查更新会据实提示，不自动上传图片或下载安装更新。

## 构建

需要 Windows、.NET 10 SDK。项目入口为 `ZeepCut.slnx`。

```powershell
dotnet build ZeepCut.slnx -c Release
# 生成自包含发布目录和 ZIP；有 Inno Setup 时同时生成安装包
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/publish.ps1
# 可显式指定 Inno Setup 编译器
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/publish.ps1 -InnoCompiler 'C:\Path\To\ISCC.exe'
```

项目已移除测试项目、验证脚本及临时记录。`scripts/build.ps1` 仅编译，`scripts/publish.ps1` 生成发布文件。最新生成物位于 `artifacts/release/`，完整自包含程序位于 `artifacts/publish/win-x64/`。发布仅编译和打包，不执行测试或启动程序验收。

保留目录：`src/`（应用源码）、`installer/`（安装包脚本）、`scripts/`（构建和发布）、`artifacts/`（最新生成物）。

首版不包含长截图、OCR、录屏、跨屏框选或云同步。
